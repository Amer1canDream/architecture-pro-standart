### <a name="_qmphm5d6rvi3"></a>**Решение**

[container](./container.puml)
[context](./context.puml)

Для решения задачи выбран отдельный сервис ставок как единый источник актуальных депозитных ставок для всех каналов: сайта, интернет-банка и кол-центра. Это позволяет исключить ручную работу с XLS-файлами, централизовать управление ставками и снизить риск расхождения данных между системами.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

Продолжить вести ставки в XLS
Минусы: ручные ошибки, нет единого источника, нет оперативности.

Читать ставки напрямую из АБС всеми каналами
Минусы: перегрузка АБС, сильная связность, сложность развития.

Передавать ставки партнёру вручную по e-mail
Минусы: нет автоматизации, риск устаревших данных, проблемы аудита.

**Недостатки, ограничения, риски**

возможна задержка синхронизации ставок между АБС и сервисом ставок

файловая интеграция через SFTP не даёт мгновенного обновления

при рассинхронизации между DC возможна выдача неактуальной ставки

появляется новый сервис, который нужно сопровождать и мониторить

для MVP часть процесса в АБС остаётся полу-ручной.
